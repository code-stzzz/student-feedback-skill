# 普通与非边界回归案例

## 通用通过条件

- 称呼正确，使用“XX爸爸妈妈好”。
- 每条包含 1～3 个合适 Emoji。
- 不虚构事实、不扩大评价范围、不改变严重程度。
- 语言自然，可直接复制到微信发送。
- 信息充分时自然分成 2～3 个短段落，段落之间空一行；信息偏少时可保留一段。
- 不把整条长反馈挤成一段，也不机械地每句话单独换行。
- 不出现内部处理语言、AI 式总结、无证据能力评价。

## N01｜多节课变化型

### 输入

> 季昱安：前面几节课表现还蛮不错的。开始学习 Python 一些库模块的应用，写代码的时候很认真，基本不会因为细节出现错误。后面发现打字速度没有那么快，所以安排了两节打字课，开始比较慢，但是后面速度慢慢跟上来了。整体学习状态不错。

### 必须体现

- 代码细节表现。
- 打字速度的前后变化。
- 整体学习状态。

### 禁止

- Python 基础扎实。
- 逻辑思维能力强。
- 编造做题正确率。

## N02｜状态改善型

### 输入

> 朱明远：明远最近上课状态比之前好很多，经常能看到他很开心。课堂上完成案例的速度也比之前快了许多，在家多加练习一下，知识点会更熟练。

### 必须体现

- 状态比之前改善。
- 情绪更开心。
- 案例完成速度变快。
- “比之前进步”是主反馈点。

### 禁止

只写“今天表现很好”而忽略前后变化。

## N03｜进步信息很多

### 输入

> 陈宇航：最近几节课状态比之前好很多，之前写代码经常漏符号，现在这种小问题少了很多。今天学习函数，开始参数和返回值容易搞混，做了几个例子之后慢慢能区分了。主动问问题也比之前多，案例完成速度快了一些，后半节状态也不错。

### 必须体现

- 最近整体进步明显。
- 至少两个具体变化作为支撑。

### 测试重点

信息很多时主动取舍，不要求把所有事实写进去。

## N04｜优秀表现防拔高

### 输入

> 孙泽宇：今天学习函数，参数和返回值理解得很快，几个案例基本都能自己完成。后面我加了一道难一点的题，他自己想了一会儿也做出来了。代码细节今天也没怎么出错，整体状态很好。

### 必须体现

- 理解较快。
- 案例能独立完成。
- 难题经过思考可以完成。

### 禁止

- 逻辑思维能力极强。
- 编程天赋突出。
- Python 基础非常扎实。

## S01｜知识会，表达不顺

### 输入

> 王浩小讲师：今天讲解 for 循环和 range，知识点自己是会的，range 三个参数是什么意思都能回答出来，但是上台讲的时候比较紧张，说话断断续续，讲解顺序也有点乱。我提醒他先讲作用再讲格式之后，后面顺很多了。

### 必须体现

- for/range 基础内容能说出来。
- range 参数可以回答。
- 表达卡顿和讲解顺序问题。
- 提醒后改善。

### 禁止

因为表达卡顿判断知识点掌握不好。

## C01｜普通课堂 + 小讲师

### 输入

> 孙浩然小讲师：今天浩然先正常上课，整体状态挺好的，前面的案例基本能自己完成。后面让他给大家讲函数，参数和返回值都能讲出来，但是讲为什么需要返回值的时候解释得不够清楚。我追问之后他能举例子说明，不过一开始组织语言有点乱。

### 必须体现

- 普通课堂：状态不错，案例基本能自己完成。
- 小讲师：参数和返回值能讲出来。
- 首次解释“为什么需要返回值”不清楚。
- 追问后能举例说明。
- 语言组织有提升空间。

### 输出要求

只输出一条综合反馈，不拆成“课堂反馈”和“小讲师反馈”。
